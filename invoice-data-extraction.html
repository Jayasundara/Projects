Completed AI Automation Project

Invoice Data Extraction Automation

Built a hybrid cloud-and-desktop automation solution to process more than 5,000 invoice files per week. Billing users uploaded invoice PDFs to SharePoint, Power Automate Cloud triggered Power Automate Desktop, the desktop workflow split PDFs into pages, sent page content to an LLM, filtered required billing information, generated structured Excel output and uploaded the result back to SharePoint.

01 / Project Background

Automating high-volume invoice review.

The company was receiving more than 5,000 invoices every week. The Billing team manually opened and reviewed invoice files to identify additional charges and other required billing information.

At this volume, the manual process consumed significant staff time and created a bottleneck in invoice review and reporting.

02 / Business Requirements

What the automation needed to deliver.

Processing Requirements

  • Automate processing of high-volume invoice PDF files.
  • Reduce repetitive manual review by the Billing team.
  • Identify and extract required invoice information, especially additional charges.
  • Use Power Automate Cloud and Power Automate Desktop together for orchestration and processing.

Data & Output Requirements

  • Use SharePoint as the input location for invoice files.
  • Use SharePoint as the final output location.
  • Produce structured Excel output for Billing review and downstream analysis.
  • Maintain the original invoice PDFs as source documents.
03 / Implemented Solution

Cloud orchestration with desktop document processing.

A SharePoint folder was configured as the invoice intake location. When Billing uploaded invoices, Power Automate Cloud detected the new files and initiated the Power Automate Desktop workflow.

The desktop automation performed the direct PDF-processing tasks, interacted with the LLM service, filtered the results and created the structured Excel output.

SharePoint Intake

Billing users started the process simply by uploading invoice PDFs to the designated SharePoint input folder.

Desktop Processing

Power Automate Desktop separated the PDFs into pages and handled the document and file operations required for AI processing.

LLM Extraction

The LLM analyzed invoice-page content and returned summarized or extracted information, which was filtered to retain the fields needed by Billing.

07 / Power Automate Cloud Flow

Simple user entry point, automated orchestration.

The cloud flow acted as the automation entry point. It monitored the designated SharePoint invoice folder for new files and passed the required file information into the desktop workflow.

This allowed the Billing team to begin processing simply by uploading invoices, without manually launching the desktop automation.

08 / Power Automate Desktop Processing

Handling the document-processing workload.

Power Automate Desktop performed the direct file and document-handling steps. It separated invoice PDFs into pages, prepared page content for analysis, interacted with the LLM service, processed the returned results and generated the Excel output.

09 / LLM Data Extraction

AI-assisted invoice interpretation.

The LLM interpreted invoice-page content and returned structured or summarized information. The workflow then filtered the response to keep the information required by Billing, particularly additional charges that previously required manual document review.

10 / Output and Data Storage

Structured results returned to SharePoint.

The extracted information was written to Microsoft Excel and the completed file was uploaded to the designated SharePoint output folder.

This gave the Billing team a centralized location for reviewing processed results while the original invoice PDFs remained available as the source documents.

11 / Technical Summary

A repeatable cloud + desktop + AI workflow.

SharePoint provided the operational intake point for more than 5,000 invoices per week. Power Automate Cloud monitored the folder and launched the Power Automate Desktop workflow when new files were received.

The desktop flow split PDFs into individual pages and sent invoice content to the LLM for analysis. The LLM extracted and summarized the required information, after which the automation filtered the results, wrote them to Excel and uploaded the completed output to SharePoint.

The implementation replaced a large portion of the repetitive manual invoice-review process with a standardized automated workflow.
