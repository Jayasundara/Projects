# Rathna Portfolio

A responsive public portfolio website built with plain HTML, CSS and JavaScript for simple GitHub Pages hosting.

## Portfolio sections

- Introduction / hero
- About
- Cloud, networking, cybersecurity, automation and AI infrastructure skills
- Selected infrastructure projects
- Experience and current technical focus
- Contact / GitHub profile

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Save.

GitHub Pages will publish `index.html` as the public site.
