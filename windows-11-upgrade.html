Completed Endpoint & AVD Modernization Project

Windows 10 to Windows 11 Upgrade

Upgraded the organization’s Windows 10 endpoint estate and Azure Virtual Desktop environment to Windows 11 ahead of the Windows 10 end-of-support deadline. Microsoft Intune was used to stage and control physical-device upgrades, while new Windows 11 AVD session-host VMs were launched with the required applications installed.

01 / Project Background

Moving the Windows estate to a supported platform.

Most business devices were still running Windows 10. With Windows 10 reaching end of support in October 2025, the endpoint estate and Azure Virtual Desktop host pools needed to move to Windows 11 so devices could remain on a supported operating system and continue receiving regular security and servicing updates.

The project covered two different upgrade paths: centrally managed physical Windows devices and the Azure Virtual Desktop environment.

Microsoft lifecycle context: Windows 10 reached end of support on October 14, 2025. The project was therefore treated as both an operating-system modernization initiative and a security/compliance requirement.
02 / Project Requirements

Upgrade scope and objectives.

  • Upgrade eligible Windows 10 business devices to Windows 11.
  • Use Microsoft Intune as the centralized deployment and update-control platform.
  • Validate the Windows 11 feature update on a limited pilot group before broad deployment.
  • Roll out the upgrade group by group to reduce operational risk.
  • Control installation and restart timing so user disruption was minimized.
  • Upgrade the Azure Virtual Desktop pools to Windows 11.
  • Ensure new AVD Windows 11 VMs contained the required business applications before users were moved to them.

04 / Intune Upgrade Design

Pilot first, then controlled production rollout.

Ring 1 — Pilot / Validation

A limited group of devices was used to test the Windows 11 feature update before the organization-wide rollout. The pilot allowed application compatibility, device behavior, upgrade success and restart experience to be validated on a smaller population first.

Ring 2 — Production

After validation, the Windows 11 upgrade was assigned to broader user/device groups. Deployment progressed in stages instead of targeting the entire organization at once, reducing risk and making failures easier to isolate and support.

Intune policy model: the Windows 11 target version was controlled through Intune’s Windows feature-update capability, while update-ring settings controlled the user experience around update delivery, installation and restarts.

05 / Phased Deployment Process

Group-by-group upgrade execution.

  1. Identified Windows 10 devices that were in scope for the Windows 11 migration.
  2. Assigned a small test population to the pilot deployment ring.
  3. Pushed the Windows 11 feature update through Microsoft Intune.
  4. Validated upgrade success and checked the pilot devices for application and user-impact issues.
  5. Expanded deployment to additional groups in controlled waves.
  6. Used Intune reporting and device status to monitor progress and identify failures or devices still awaiting upgrade.
  7. Continued the rollout until all targeted managed devices had been processed.
06 / Installation & Restart Control

Minimizing disruption to remote users.

Although the Windows 11 upgrade was pushed centrally through Intune, installation and restart behavior was configured to reduce impact during working hours. The project scheduled upgrade activity and restarts for after-hours periods wherever possible so users were less likely to lose active work or be interrupted during the business day.

Central Deployment

Users did not have to manually source or install Windows 11; deployment was centrally controlled through Intune.

After-Hours Installation

Installation timing was aligned to non-business hours to reduce disruption to productivity.

Controlled Restarts

Restart behavior was managed through Windows Update policy settings instead of relying on unmanaged user action.

07 / Azure Virtual Desktop Upgrade

Refreshing the AVD pools with Windows 11 hosts.

The AVD environment required a different approach from physical endpoints. New Windows 11 virtual machines were launched for the host pools and prepared with the required business applications before production use.

Windows 11 Session Hosts

New Windows 11 client/session-host VMs were created for the Azure Virtual Desktop environment, providing a supported Windows 11 platform for remote desktop users.

Application Readiness

Required applications were installed on the new Windows 11 VMs before they were used as production AVD capacity, helping maintain the application experience users expected from the existing pools.

10 / Technical Summary & Closure

Project closure.

The Windows 10 to Windows 11 upgrade project modernized both the physical endpoint estate and the Azure Virtual Desktop environment. Microsoft Intune provided the centralized control plane for endpoint feature-update deployment, allowing the organization to validate Windows 11 on a pilot group before moving into a phased production rollout.

Updates were deployed group by group, with installation and restart behavior scheduled outside normal working hours to reduce disruption. In parallel, new Windows 11 AVD virtual machines were launched and prepared with the required applications, providing a supported Windows 11 platform for virtual desktop users.
