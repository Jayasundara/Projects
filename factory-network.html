01 / Project Background

Modernizing the network before modernizing the factory.

The factory environment was operating on aging network infrastructure. When the Smart Factory project was initiated, network readiness became the first major technical challenge because the existing infrastructure did not provide the structured backbone, distribution capacity, and access-layer design required for new digital systems.

02 / Project Requirements

What the network needed to deliver.

  • Redesign and rebuild the factory network to support the Smart Factory project.
  • Provide a reliable high-speed backbone between the CBL data center and the factory.
  • Create structured network distribution points throughout the factory.
  • Support wireless access points and IP phones using Power over Ethernet (PoE).
  • Provide standard data connectivity for PCs, production devices, and other wired endpoints.
  • Improve network manageability and provide a scalable foundation for future factory systems.
03 / Implemented Solution

Hierarchical fiber-based factory network.

The network was rebuilt using a hierarchical design consisting of the CBL data center/core network, an 8-core fiber backbone, and four factory distribution points. Each distribution point provided local access connectivity for both powered network devices and standard data devices.

Implemented factory network architecture.

The completed high-level architecture uses the fiber backbone to connect the data center to four distribution points. At each distribution point, data switching serves regular wired endpoints while PoE switching serves wireless access points and IP phones.

06 / Network Design

Access and distribution layers designed for the factory.

6.1 Fiber Backbone

An 8-core fiber cable was installed between the CBL data center and the factory. This provided the backbone required to carry factory network traffic back to the core environment and created the physical foundation for the four distribution points.

6.2 Distribution Layer

Four main distribution points were introduced to decentralize access connectivity across the factory. This reduced dependency on long copper runs and provided local switching points closer to users, wireless devices, phones, and production endpoints.

6.3 PoE Network

PoE switches were installed for devices requiring both network connectivity and electrical power over Ethernet. These switches were used for wireless Access Points and IP Phones, simplifying installation by avoiding separate power connections at each endpoint.

6.4 Data Network

Separate data switches were installed for normal wired network connectivity. These switches provided connections for user PCs, factory data devices, and other regular Ethernet endpoints while keeping the access-layer design organized and easier to maintain.

07 / Smart Factory Enablement

The network became the foundation for digital factory systems.

The redesigned backbone and distribution architecture provided the connectivity required for tablets, wireless access, production applications, digital data-entry systems, IP communications, and other factory technologies introduced as part of the modernization program.

08 / Technical Summary

A scalable, supportable factory network.

The modernization replaced an aging and difficult-to-expand network with a structured fiber-based architecture. An 8-core fiber backbone was installed from the CBL data center to the factory, and four main distribution points were created to provide local access connectivity. Each distribution point used PoE switching for wireless Access Points and IP Phones and standard data switching for PCs and other wired devices.

The redesigned network provided the stable connectivity foundation required to proceed with the Smart Factory project and improved the overall scalability, supportability, and organization of the factory network.
